CONTENU
- index.html : page principale

- script.js : menu mobile et formulaire
- images/kongosec-hero.png : visuel KongoSec
- README.txt : instructions

TEST LOCAL
1. Décompresser le ZIP.
2. Ouvrir index.html dans Chrome.

MISE EN LIGNE GITHUB PAGES
1. Ouvrir le dépôt GitHub de KongoSec.
2. Upload files et envoyer TOUS les fichiers en conservant le dossier images.
3. Settings > Pages.
4. Source : Deploy from a branch.
5. Branch : main ; dossier : / (root).
6. Save.
7. Attendre le déploiement puis ouvrir l'URL fournie par GitHub.

IMPORTANT AVANT PUBLICATION
- Remplacer contact@kongosec.cd dans script.js par l'adresse réelle.
- Remplacer les coordonnées fictives éventuelles.
- Ne pas publier de faux chiffres, faux clients ou certifications non obtenues.
- Le visuel est un prototype marketing ; il ne constitue pas une preuve de certification.

Le site est volontairement statique : il peut être publié gratuitement avec GitHub Pages.
